# Official DepEd guides: sources

All files were retrieved on 2026-09-25. Scope is ICT and Computer Programming only.

The Three-Term Budget of Work (BOW) files are published by DepEd on the LR Portal,
one page per grade: https://sites.google.com/deped.gov.ph/deped-lrportal/three-term-budget-of-work-bow
Each is a Google Drive file embedded on that page. Every downloaded PDF's embedded
title was checked against its listing, and all are marked "Last updated April 7, 2026".

## Not included

- Grades 11 and 12: the LR Portal has no TLE or ICT budget of work
  (three-term-budget-of-work-bow/grade-11 lists core subjects only; grade-12 is empty).
- SHS ICT Support and Computer Programming Technologies: the LR Portal page
  (strengthened-shs-learning-resources/shs-tech-pro-electives/shs-ict-support-and-commputer-programming)
  carries only Contact Center Servicing learning materials, not a curriculum guide.
  A search of deped.gov.ph found the Strengthened SHS program page
  (https://www.deped.gov.ph/strengthened-shs-program/) but no ICT or programming guide PDF yet.
